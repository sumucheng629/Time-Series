# Report Drafting Map

This map links each planned report section to the evidence already generated by
the workflow. It is a planning document, not a completed report.

## Main Report

| Section | Evidence to use | Drafting focus |
| --- | --- | --- |
| Research question | `notes/project_plan.md` | Refine one clear question about long-run change and short-term forecasting. |
| Data | `outputs/tables/series_summary.csv`, `outputs/tables/data_validation_checks.csv` | State time span, selected measures, and validation checks. |
| Exploratory analysis | `annual_series_overview.png`, `annual_first_differences.png`, `descriptive_features.csv` | Describe visible trends and annual changes without overloading the report. |
| Transformation and stationarity | `scale_comparison.png`, `transformation_screen.csv`, `stationarity_screen.csv` | Explain whether original scale, log scale, and differencing need consideration. |
| Candidate models | `candidate_model_registry.csv`, `forecast_design.csv` | Explain the model set and the training/holdout split. |
| Diagnostics and evaluation | `model_selection_evidence.csv`, `candidate_residual_acf.png`, `holdout_forecast_comparison.png` | Compare accuracy and residual evidence before selecting final models. |
| Forecast discussion | `five_year_candidate_forecasts.png` | Discuss uncertainty and limitations carefully. |

## Drafting Guardrails

- Do not copy this map into the final report as prose.
- Do not choose a model using RMSE alone.
- Do not hide residual diagnostics that contradict a simple model choice.
- Keep extra tables in the appendix unless they directly support the main
  argument.
- Use `notes/table_review_checklist_2026-06-03.md` to decide which table
  evidence belongs in the main text and which belongs in the appendix.
